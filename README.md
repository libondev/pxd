# PXD
A universal UI component library for Vue2&3

> [!WARNING]
> The project is under active development and is not ready for production.

[Online Preview](https://pxd-ui.netlify.app/)

## Contribution

### Dev

```shell
pnpm install

pnpm dev
```

### Build

#### Core

```shell
pnpm build
```

#### Docs

```shell
pnpm build:docs
```
