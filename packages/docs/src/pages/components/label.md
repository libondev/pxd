# Label

A styled native label element for form field captions.

## Default

```vue demo
<template>
  <PStack class="max-w-sm" direction="vertical">
    <PLabel for="username">Username</PLabel>
    <PInput id="username" placeholder="Enter your username" />
  </PStack>
</template>
```

## Slots

| Name | Description |
| --- | --- |
| default | Label text. |
