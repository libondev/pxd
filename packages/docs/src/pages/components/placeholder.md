# Placeholder
Indicates that it is not empty here.

## Default

```vue demo
<template>
  <PPlaceholder></PPlaceholder>
</template>
```

## Custom
Customize its size and line color.

```vue demo
<template>
  <PPlaceholder color="#8e51ff" height="160px" width="160px" class="border-blue-900"></PPlaceholder>
</template>
```
