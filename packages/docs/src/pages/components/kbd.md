# Kbd
Display keyboard input that triggers an action.

## Modifiers

```vue demo
<template>
  <PStack>
    <PKbd meta />
    <PKbd shift />
    <PKbd alt />
    <PKbd ctrl />
  </PStack>
</template>
```

## Combination

```vue demo
<template>
  <PKbd meta shift/>
</template>
```

## Small

```vue demo
<template>
  <PKbd small>/</PKbd>
</template>
```
