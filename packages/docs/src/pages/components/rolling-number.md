# Rolling Number

Display a number with a rolling animation effect, supporting decimals and thousands separators.

## Default

```vue demo
<template>
  <PRollingNumber :value="3000" />
</template>
```

## Thousands

```vue demo
<template>
  <PRollingNumber :value="3000" thousands />
</template>
```

## Durations

```vue demo
<template>
  <PRollingNumber :value="3000" :durations="5000" />
</template>
```
